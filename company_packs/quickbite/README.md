# QuickBite Company Pack

Everything the operator knows about how QuickBite works, stored as data rather
than prompts:

- `sops/` — one standard operating procedure per ticket type (Markdown)
- `policies/` — refund, compensation and approval rules (YAML)
- `systems.yaml` — the internal systems and how to reach them
- `permissions.yaml` — which actions the operator may take in each system

Built in step 3.
